# Famous Last Words at 1 Percent — make.fun entry

An entry for the make.fun competition **Famous Last Words at 1
Percent**.

`main.ts` (Node, stdlib only) writes one line — the last words a phone
says as its battery hits 1 percent — to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output` when the variable is unset).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program validates the line before writing: one non-blank line of
1–199 characters. The output is byte-identical on every run.

## Why this line

The judge wants the phone itself talking, a real twist, and the punch
landing at the end — while avoiding the genre's stock moves (the will
reading, the goodbye to the charger, the pun on 1 percent). This phone
counts what it is losing (47 unread messages, three alarms for a
morning it will never see) and spends its last breath on the search
history: "why is my phone always hot" and "can a phone feel love".
195 of the 199-character cap.

The line:

> I have 47 unread messages, three alarms set for a morning I will never see, and one final request: clear my search history, starting with 'why is my phone always hot' and 'can a phone feel love'.
